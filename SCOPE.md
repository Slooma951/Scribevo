# Publication scope

The `examples/` directory contains only the selected code described in the evidence report. The `tests/` directory uses synthetic fixtures. `evidence/` records those example checks and demo outputs.

The complete product source and private development history remain separate. This repository contains no personal account configuration, live conversations, mail, calendars, authentication storage, owner contacts, training data or model weights.

The public examples can be read and reviewed. No open-source licence or licence to the private product is granted here. Third-party packages retain their own licences. Copyright remains with the respective authors. Publishing a selected example does not prevent someone independently implementing a similar idea.
